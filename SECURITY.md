# Security Policy

## Supported Versions

Emgu CV is actively developed on the `EMGUCV_5_0` branch. Security fixes are
provided for the latest 5.0.x release. Older major versions (4.x and earlier)
are no longer actively maintained and do not receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 5.0.x   | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Emgu CV, please report it
privately rather than opening a public GitHub issue.

- Preferred: use GitHub's [private vulnerability reporting](https://github.com/emgucv/emgucv/security/advisories/new)
  for this repository.
- Alternatively, email **support@emgu.com** with details of the issue,
  including steps to reproduce and the affected version/platform.

Please do not disclose the vulnerability publicly until it has been
triaged and a fix or mitigation is available.

We'll acknowledge your report as soon as possible and keep you updated as
the issue is investigated and resolved.
